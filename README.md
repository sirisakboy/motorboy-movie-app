# 🎬 MotorBoy Movie App

[![Android App](https://img.shields.io/badge/Platform-Android-green.svg)](https://play.google.com/store)
[![Kotlin](https://img.shields.io/badge/Language-Kotlin-purple.svg)](https://kotlinlang.org)
[![Jetpack Compose](https://img.shields.io/badge/UI-Jetpack%20Compose-blue.svg)](https://developer.android.com/jetpack/compose)

**MotorBoy Movie App** is a sleek, modern movie exploration application built with cutting-edge Android technologies. Experience a cinematic interface with smooth transitions, dynamic content, and a user-centric design.

---

## ✨ Key Features

- 🚀 **Modern UI/UX**: Built entirely with **Jetpack Compose** for a fluid and responsive interface.
- 🔍 **Smart Search**: Find your favorite movies instantly.
- 🍿 **Explore & Discover**: Browse movies by categories, trends, and genres.
- 🎞️ **Immersive Player**: A dedicated screen for a seamless viewing experience.
- 📋 **Personalized Watchlist**: Keep track of the movies you want to watch.
- 👤 **User Profiles**: Manage your preferences and account.

## 🛠️ Tech Stack

- **Language:** [Kotlin](https://kotlinlang.org/)
- **UI Framework:** [Jetpack Compose](https://developer.android.com/jetpack/compose)
- **Architecture:** MVVM (Model-View-ViewModel)
- **State Management:** ViewModel & StateFlow
- **Build System:** Gradle (KTS)

## 📦 How to Build APK from Web URL (The "Magic" Link)

If you want to convert a Web App/URL into a professional Android APK without writing complex code, the fastest and coolest way is using a **Web-to-APK wrapper**. 

### 🚀 The One-Click Method:
Use **[WebIntoApp](https://www.webintoapp.com/)** or **[AppGeyser](https://appgeyser.com/)**.

**Step-by-step:**
1. 🔗 **Copy your Web App URL** (e.g., `https://your-movie-app.vercel.app`).
2. 🌐 Go to **[WebIntoApp](https://www.webintoapp.com/)**.
3. 📥 **Paste the Link** $\rightarrow$ Upload your **Icon** $\rightarrow$ Enter **App Name**.
4. ⚙️ Click **"Build App"**.
5. 📩 **Download your `.apk` file** and install it on your phone!

> **Pro Tip:** To avoid "Unknown Sources" warnings, you can sign your APK with a digital key or upload it to the Google Play Store.

## 🚀 Getting Started (For Developers)

### Prerequisites
- Android Studio Flamingo or newer.
- JDK 17+.

### Installation
1. Clone the repository:
   ```bash
   git clone https://github.com/yourusername/motorboy-movie-app.git
   ```
2. Open the project in **Android Studio**.
3. Sync Gradle files.
4. Run on an emulator or physical device:
   ```bash
   ./gradlew installDebug
   ```
